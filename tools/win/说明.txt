Windows 远程调试环境 · 配置说明（v3 · 婉宜 10-08）
=====================================================

★ 推荐这样跑（最稳，绕开一切批处理坑）：
  1. 把这个文件夹整个拷到那台 Windows 上（例如桌面）。
  2. 开始菜单搜「PowerShell」→ 右键「以管理员身份运行」。
  3. 粘贴执行这两行（把路径改成你放的位置）：
       cd $env:USERPROFILE\Desktop\win-debug-setup
       Set-ExecutionPolicy -Scope Process Bypass -Force; .\setup-remote-access.ps1
  4. 跑完最后会显示一段「请把下面这段发给我」，同时存一份报告到桌面。

备用跑法：双击「一键配置调试环境.bat」——它会自己申请管理员权限（只需点一次 UAC「是」）。
  v3 已修掉「不停弹窗口」：以前用 fltmc 判权限，你这台机器 PATH 不全（fltmc: 不是内部或外部命令）
  → 误判成没权限 → 反复提权。现在改成三重探测 + 提权标记，结构上不可能再循环。

【它做什么】全程幂等，重复跑没事，不删任何东西
  1) 体检：系统/架构/管理员、出网、代理、TEMP/NODE_PATH/NODE_OPTIONS（裸盘符会标红）、
     已装 ShipScheduleHub（注册表 + 各安装位置）、Chrome/Edge、Node、WebView2 运行时、
     长路径开关、各安装目录可写性。
  2) Tailscale：没装就装（winget → 官方安装包兜底）；没登录则给登录链接并等你完成；最后报 Tailscale IP。
  3) OpenSSH Server：装（Windows 功能 → Win32-OpenSSH 压缩包兜底）、开机自启、默认 shell=PowerShell、
     防火墙只放 Tailscale 网段（100.64.0.0/10）、写入调试公钥（带正确 ACL）。
  4) 自检 + 报告（桌面 txt）+ 关键信息复制到剪贴板。

【排障】万一没跑通：
  · 日志：%TEMP%\ssh-setup\setup-log.txt（脚本全程写入，窗口一闪也有证据）
  · 报告：桌面 ssh-setup-report-*.txt
  · 把这两个文件里任意一个发我即可。
  · 安全软件拦截：右键文件 → 属性 → 勾「解除锁定」；或直接把 setup-remote-access.ps1 用记事本打开
    看内容（它是明文脚本，不含编译产物）。

【安全】SSH 只对 Tailscale 网段开放；只装一把公钥（hermes-debug@mac），可随时删
  C:\ProgramData\ssh\administrators_authorized_keys
